# MacBook Landing Page

<p>
A modern and interactive <strong>MacBook Landing Page</strong> built with
<strong>Vite, HTML, JavaScript, Three.js, Tailwind CSS, GSAP, and Lenis</strong>.
</p>

<p>
The project features an interactive <strong>3D MacBook model</strong>, smooth scrolling,
scroll-based animations, and a responsive modern user interface inspired by Apple's product presentation style.
</p>

<h2>Live Demo</h2>

<p>
<a href="https://macbook-landing-page-cyan.vercel.app/" target="_blank">
View Live Website
</a>
</p>

<hr>

<h2>Features</h2>

<ul>
  <li>Interactive 3D MacBook model using <strong>Three.js</strong></li>
  <li>Interactive 3D model controls</li>
  <li>Smooth animations using <strong>GSAP</strong></li>
  <li>Scroll-based animations using <strong>GSAP ScrollTrigger</strong></li>
  <li>Smooth scrolling using <strong>Lenis</strong></li>
  <li>Modern UI built with <strong>Tailwind CSS</strong></li>
  <li>Fast development and build process using <strong>Vite</strong></li>
  <li>Responsive design</li>
  <li>Deployed on <strong>Vercel</strong></li>
</ul>

<h2>Installation and Setup</h2>

<h3>1. Clone the Repository</h3>

<p>
Replace the URL below with your actual GitHub repository URL.
</p>

<pre><code>git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
</code></pre>

<h3>2. Navigate to the Project Folder</h3>

<pre><code>cd YOUR-REPOSITORY
</code></pre>

<h3>3. Install Dependencies</h3>

<pre><code>npm install
</code></pre>

<h3>4. Start the Development Server</h3>

<pre><code>npm run dev
</code></pre>

<p>
After running the command, Vite will provide a local development URL, usually:
</p>

<pre><code>http://localhost:5173
</code></pre>

<hr>

<h2>Build for Production</h2>

<p>To create an optimized production build:</p>

<pre><code>npm run build
</code></pre>

<p>To preview the production build locally:</p>

<pre><code>npm run preview
</code></pre>

<h2>Three.js</h2>

<p>
<strong>Three.js</strong> is used to create the interactive 3D experience of the MacBook.
The project uses Three.js for:
</p>

<ul>
  <li>Loading 3D models</li>
  <li>Camera positioning</li>
  <li>Lighting</li>
  <li>Rendering</li>
  <li>User interaction</li>
  <li>3D model controls</li>
  <li>GLB/GLTF model support</li>
</ul>

<hr>

<h2>Animations</h2>

<p>
<strong>GSAP</strong> is used to create smooth and engaging animations throughout the website.
</p>

<ul>
  <li>Scroll-based animations</li>
  <li>Element reveal animations</li>
  <li>Stagger animations</li>
  <li>Timeline animations</li>
  <li>Interactive transitions</li>
</ul>

<p>
<strong>GSAP ScrollTrigger</strong> connects animations with the user's scrolling behavior.
</p>

<hr>

<h2>Smooth Scrolling</h2>

<p>
<strong>Lenis</strong> is used to provide a smooth and modern scrolling experience.
It works alongside GSAP and ScrollTrigger to create smooth scroll-based interactions.
</p>

<hr>

<h2>Deployment</h2>

<p>
This project is deployed using <strong>Vercel</strong>.
</p>

<h3>Deployment Process</h3>

<ol>
  <li>Push the project to GitHub.</li>
  <li>Import the repository into Vercel.</li>
  <li>Configure the project as a Vite application.</li>
  <li>Vercel automatically installs the dependencies.</li>
  <li>Vercel builds and deploys the project.</li>
</ol>
